kiln 命令行

在命令提示符、PowerShell 或你自己的脚本中，用与应用相同的引擎和预设转换文件，或让文件夹自动转换放入的文件。一切都在你的电脑上完成。

设置 kiln 命令

  1. 1

    在安装程序中保持勾选

    在 Kiln 安装程序的选项页面保持勾选 将 "kiln" 命令添加到 PATH（默认已勾选）。已经安装过？再运行一次最新的安装程序即可。

  2. 2

    打开新的终端

    打开新的命令提示符、PowerShell 或 Windows 终端窗口（之前已打开的窗口看不到新的 PATH），运行 kiln version。

  3. 3

    便携版或不使用 PATH

    所需文件都在 Kiln 文件夹中：直接运行其中的 kiln-cli.exe，或自行把 cli 文件夹添加到 PATH。无需运行 Kiln 应用。

快速上手

可以传入文件名、*.heic 这样的通配符或整个文件夹。不加 -o 时，结果保存在原文件旁边。

  • 把一张照片转成 JPG

    kiln convert photo.heic --to jpg

  • 所有 PNG 转成质量 80 的 WebP，存到一个文件夹

    kiln convert *.png --to webp --quality 80 -o converted

  • 用预设转换文件夹及其子文件夹

    kiln convert D:\Scans --recursive --preset to-pdf

  • 自动生成 PDF 的收件箱文件夹

    kiln watch D:\Inbox --to pdf --move-originals

  • HEIC 能转换成什么？

    kiln formats heic

  • 查看你的预设（ID 和名称）

    kiln presets

kiln convert

kiln convert <files or folders...> (--to <format> | --preset <preset>) [options]

转换文件、通配符（*.heic）和文件夹。传入文件夹时会转换其中 Kiln 认识的文件，加 -r 则包括子文件夹。目标格式和预设二选一。

选项

-t, --to <format>目标格式（ID 或扩展名）：jpg、png、webp、pdf、docx、hwpx、mp4、mp3…（见 kiln formats）
-p, --preset <preset>应用中的预设，按 ID 或名称（见 kiln presets）
-o, --output <folder>保存到该文件夹，而不是原文件旁边
-r, --recursive包括子文件夹
-q, --quality <1-100>JPG、WebP、AVIF 等有损图像的质量
--overwrite覆盖已存在的输出文件（默认在新文件名后加编号）
--skip保留已存在的输出文件
--keep-dates让转换后的文件沿用原文件的创建和修改日期
--json以一个 JSON 文档输出结果，便于脚本读取
--quiet除错误外不输出任何内容

kiln watch

kiln watch <folder> (--to <format> | --preset <preset>) [options]

持续转换放入文件夹的每个文件，按 Ctrl+C 停止。不加 -o 时，转换后的文件保存在该文件夹下的 converted 文件夹中。

选项

-t, --to <format>目标格式
-p, --preset <preset>应用中的预设，按 ID 或名称
-o, --output <folder>转换后文件的保存位置（默认：<文件夹>\converted）
-r, --recursive同时监视子文件夹（转换结果也保存在相同的子文件夹中）
--move-originals把转换过的原文件移到 <文件夹>\originals，并在启动时转换已在等待的文件
--settle <seconds>文件需保持不变多少秒后才转换（默认 2）
--keep-dates让转换后的文件沿用原文件的创建和修改日期
--quiet除错误外不输出任何内容

kiln formats

kiln formats [<format>]

列出所有格式的 ID 和扩展名，或某个格式能转换成什么，以及安装可选引擎后还能转换成的格式。

kiln presets

kiln presets

列出内置预设和你在应用中创建的预设，包括 ID、名称和目标格式。

kiln help

kiln help [<command>]
kiln version

显示全部命令或某个命令的用法，以及已安装的版本。

自动转换文件夹

下载、扫描、其他应用导出的文件，放进文件夹就会自动转换。

  • 文件完整后才转换，也就是大小不再变化、没有其他程序占用，所以正在下载或复制很久的文件也不会出问题。
  • 忽略临时和隐藏文件（.crdownload、.part、.tmp、~$ 文件）以及 Kiln 不认识的格式。
  • 转换后的文件保存到监视文件夹下的 converted 文件夹，或 -o 指定的位置。加 -r 时，子文件夹中的文件会按原来的子文件夹结构保存（2025\a.png → converted\2025\a.pdf）。
  • 使用 --move-originals 时，转换过的原文件会移到 originals，文件夹就像收件箱一样；启动时已在等待的文件也会转换。

或者在应用中后台运行

Kiln 的 自动转换文件夹 页面无需终端也能做到：添加文件夹并为每个文件夹选择预设，Kiln 在托盘中运行时就会自动转换。

在脚本中使用

--json 会输出一个包含每个文件结果的 JSON 文档，退出码则告诉脚本执行结果。

--json

{
  "preset": "WEBP",
  "target": "webp",
  "converted": 2,
  "skipped": 0,
  "failed": 1,
  "files": [
    {
      "source": "D:\\Exports\\cover.png",
      "state": "done",
      "outputs": [ "D:\\Exports\\cover.webp" ]
    },
    {
      "source": "D:\\Exports\\broken.png",
      "state": "failed",
      "outputs": [],
      "error": "The engine reported an error (improper image header)"
    }
  ]
}

退出码

0没有失败的文件
1部分文件失败（其余已转换）
2参数错误、未知的格式或预设、输入文件不存在
3没有可转换的文件

PowerShell 示例

$result = kiln convert D:\Exports\*.png --to webp --json | Out-String | ConvertFrom-Json
if ($LASTEXITCODE -eq 1) {
  $result.files | Where-Object state -eq 'failed' | ForEach-Object { "$($_.source): $($_.error)" }
}

须知

  • 与应用共用引擎和预设。在 Kiln 中创建或修改的预设，马上就能用 --preset 按 ID 或名称调用。
  • 可选引擎（FFmpeg、LibreOffice 等）在应用的“设置 → 引擎”中安装。用 kiln formats <格式> 可查看哪些转换需要引擎。
  • 通配符由 kiln 自己展开，所以在命令提示符中也能像在 PowerShell 中一样使用 *.heic。含空格的路径请加引号。
  • 和应用一样在你的电脑上转换，不上传任何文件，也不需要联网。
  • 命令行消息统一用英文，因此脚本和日志在任何电脑上都一样。

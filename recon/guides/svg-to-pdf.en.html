How to convert SVG to PDF on Windows

  1. 1

    Select your SVG files

    In File Explorer or on the desktop, select one SVG file or as many as you like.

  2. 2

    Hold Ctrl and drag

    Hold Ctrl (or the key you set in Kiln) and drag the files. A donut of formats opens at the cursor. Prefer menus? Right-click and choose Convert with Kiln.

  3. 3

    Drop on PDF

    Release the files over PDF. A progress ring counts up, and each PDF file is saved next to its original.

What Kiln does for SVG → PDF

SVG to PDF stays vector: lines and text remain sharp at any zoom and in print, and the file stays small. Handy for sending logos and diagrams to a print shop or putting them into documents.

  • Built in: works right after installing Kiln, with nothing else to download.
  • The merge preset combines all dropped files into one PDF.
  • Batch: one file or hundreds, converted in parallel; a failure never stops the rest.
  • Private: files are converted on your PC and never uploaded, even without internet.
  • Saved next to the original, or in a folder and with a file name pattern you choose.

About SVG and PDF

SVG

SVG

SVG vector graphic

SVG is an XML-based vector graphics format. Shapes and text stay sharp at any size, which makes it ideal for logos and icons on the web, but many apps and upload forms only accept pixel images.

Extensions: .svg

All vector graphics formats

PDF

PDF

PDF document

PDF is the standard for sharing documents that must look the same everywhere. Fonts, layout and images are fixed, and it opens on any device. That also makes PDFs hard to edit.

Extensions: .pdf

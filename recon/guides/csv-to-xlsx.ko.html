CSV를 XLSX로 변환

Windows 10·11에서 CSV 파일을 XLSX로 바꿔 보세요. 무료이고, 인터넷 없이 여러 개를 한 번에 변환해요. 파일을 끌어 형식 도넛의 XLSX에 놓으면 원본 옆에 XLSX 파일이 생겨요.

Windows에서 CSV를 XLSX로 변환하는 방법

  1. 1

    CSV 파일 고르기

    탐색기나 바탕화면에서 CSV 파일을 하나 또는 여러 개 고르세요.

  2. 2

    Ctrl 누른 채 끌기

    Ctrl(또는 Kiln에서 정한 키)을 누른 채 파일을 끌면 커서 위치에 형식 도넛이 열려요. 메뉴가 편하다면 우클릭 메뉴에서 바로 변환할 수도 있어요.

  3. 3

    XLSX에 놓기

    XLSX 칸 위에서 손을 떼면 진행률 링이 차오르고, XLSX 파일이 원본 옆에 저장돼요.

Kiln의 CSV → XLSX 변환

XLSX 통합 문서에는 CSV에 없는 서식·수식·여러 시트를 담을 수 있습니다. CSV 내보내기 파일을 모두 골라 한 번에 놓으면 파일마다 통합 문서가 하나씩 만들어져, 엑셀에서 하나씩 가져올 필요가 없어요.

  • 기본 내장: Kiln만 설치하면 추가로 받을 것 없이 바로 됩니다.
  • MS 오피스나 LibreOffice가 필요 없습니다.
  • 일괄 변환: 파일 하나든 수백 개든 동시에 변환하고, 하나가 실패해도 나머지는 계속됩니다.
  • 개인정보 보호: 내 PC에서 변환하고 파일을 업로드하지 않습니다. 인터넷 없이도 됩니다.
  • 저장 위치: 원본 옆 또는 원하는 폴더에, 원하는 파일 이름 규칙으로 저장합니다.

CSV(쉼표로 구분된 값)

CSV는 한 줄에 표의 한 행을 적는 텍스트 형식입니다. 모든 스프레드시트·데이터베이스·프로그래밍 언어가 읽을 수 있지만 서식·수식·여러 시트는 담지 못합니다.

엑셀 통합 문서

XLSX는 엑셀 2007부터 쓰이는 Microsoft Excel 통합 문서 형식으로, 한 파일에 수식·서식·차트·그림이 있는 여러 시트를 담을 수 있습니다.

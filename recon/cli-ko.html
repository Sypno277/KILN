kiln 명령줄

명령 프롬프트, PowerShell, 직접 만든 스크립트에서 앱과 같은 엔진과 프리셋으로 파일을 변환하거나, 폴더에 들어오는 파일을 알아서 변환하게 할 수 있어요. 변환은 모두 내 PC에서 해요.

웹 스튜디오에서 변환 명령어 보기

kiln 명령 설정하기

  1. 1

    설치할 때 체크 유지

    Kiln 설치 프로그램의 옵션 화면에서 "kiln" 명령어를 PATH에 추가를 체크된 상태로 두세요(기본으로 켜져 있어요). 이미 설치했다면 최신 설치 파일을 한 번 더 실행하면 돼요.

  2. 2

    새 터미널 열기

    명령 프롬프트, PowerShell, Windows 터미널 창을 새로 열고(이미 열려 있던 창은 바뀐 PATH를 몰라요) kiln version을 실행해 보세요.

  3. 3

    포터블이거나 PATH 없이

    필요한 파일은 모두 Kiln 폴더에 있어요. 그 안의 kiln-cli.exe를 실행하거나 cli 폴더를 직접 PATH에 추가하세요. 앱이 실행 중일 필요는 없어요.

빠르게 시작하기

파일 이름, *.heic 같은 와일드카드, 폴더를 통째로 넘길 수 있어요. -o를 주지 않으면 결과는 원본 옆에 저장돼요.

  • 사진 한 장을 JPG로

    kiln convert photo.heic --to jpg

  • 모든 PNG를 품질 80 WebP로, 한 폴더에

    kiln convert *.png --to webp --quality 80 -o converted

  • 하위 폴더까지 프리셋으로 변환

    kiln convert D:\Scans --recursive --preset to-pdf

  • PDF를 만들어 주는 받은편지함 폴더

    kiln watch D:\Inbox --to pdf --move-originals

  • HEIC는 무엇으로 바꿀 수 있을까?

    kiln formats heic

  • 내 프리셋 목록(ID와 이름)

    kiln presets

kiln convert

kiln convert <files or folders...> (--to <format> | --preset <preset>) [options]

파일, 와일드카드(*.heic), 폴더를 변환해요. 폴더를 주면 그 안에서 Kiln이 아는 파일을 변환하고, -r을 붙이면 하위 폴더까지 포함해요. 대상 형식이나 프리셋 중 하나를 지정하세요.

옵션

-t, --to <format>대상 형식(ID나 확장자): jpg, png, webp, pdf, docx, hwpx, mp4, mp3… (kiln formats 참고)
-p, --preset <preset>앱에 있는 프리셋, ID나 이름으로(kiln presets 참고)
-o, --output <folder>원본 옆 대신 이 폴더에 저장
-r, --recursive하위 폴더 포함
-q, --quality <1-100>JPG, WebP, AVIF 같은 손실 압축 이미지의 품질
--overwrite같은 이름의 결과 파일이 있으면 덮어쓰기(기본은 새 이름에 번호를 붙여요)
--skip같은 이름의 결과 파일이 있으면 그대로 두기
--keep-dates변환한 파일에 원본의 만든 날짜와 수정한 날짜를 그대로 넣기
--json결과를 스크립트용 JSON 하나로 출력
--quiet오류 말고는 아무것도 출력하지 않기

kiln watch

kiln watch <folder> (--to <format> | --preset <preset>) [options]

Ctrl+C를 누를 때까지 폴더에 들어오는 파일을 모두 변환해요. -o를 주지 않으면 변환된 파일은 그 폴더 안의 converted 폴더에 저장돼요.

옵션

-t, --to <format>대상 형식
-p, --preset <preset>앱에 있는 프리셋, ID나 이름으로
-o, --output <folder>변환된 파일을 저장할 곳(기본: <폴더>\converted)
-r, --recursive하위 폴더도 감시 (변환 결과도 같은 하위 폴더에 저장)
--move-originals변환한 원본을 <폴더>\originals로 옮기고, 시작할 때 이미 기다리던 파일도 변환
--settle <seconds>파일이 몇 초 동안 바뀌지 않아야 변환할지(기본 2초)
--keep-dates변환한 파일에 원본의 만든 날짜와 수정한 날짜를 그대로 넣기
--quiet오류 말고는 아무것도 출력하지 않기

kiln formats

kiln formats [<format>]

모든 형식의 ID와 확장자, 또는 한 형식이 무엇으로 바뀔 수 있는지 보여 줘요. 추가 엔진을 받으면 늘어나는 형식도 알려 줘요.

kiln presets

kiln presets

기본 프리셋과 앱에서 만든 프리셋을 ID, 이름, 대상 형식과 함께 보여 줘요.

kiln help

kiln help [<command>]
kiln version

모든 명령이나 명령 하나의 사용법, 그리고 설치된 버전을 보여 줘요.

자동 변환 폴더

다운로드, 스캔, 다른 앱에서 내보낸 파일까지, 폴더에 넣기만 하면 알아서 변환되게 할 수 있어요.

  • 파일이 완성된 뒤에 변환해요. 크기가 더 이상 바뀌지 않고 다른 프로그램이 열고 있지 않을 때까지 기다리니까, 다운로드 중이거나 복사가 오래 걸려도 안전해요.
  • 임시·숨김 파일(.crdownload, .part, .tmp, ~$ 파일)과 Kiln이 모르는 형식은 무시해요.
  • 변환된 파일은 감시하는 폴더 안의 converted 폴더나 -o로 지정한 곳에 저장돼요. -r을 쓰면 하위 폴더의 파일은 그 하위 폴더 구조대로 저장돼요(2025\a.png → converted\2025\a.pdf).
  • --move-originals를 쓰면 변환한 원본을 originals로 옮겨요. 폴더가 받은편지함처럼 동작하고, 시작할 때 이미 기다리던 파일도 변환해요.

앱에서 백그라운드로

Kiln의 자동 변환 폴더 화면에서는 터미널 없이 똑같이 할 수 있어요. 폴더를 추가하고 폴더마다 프리셋을 고르면, Kiln이 트레이에서 실행되는 동안 변환해요.

스크립트에서 쓰기

--json은 파일마다 결과가 담긴 JSON 하나를 출력하고, 종료 코드로 스크립트가 결과를 알 수 있어요.

--json

{
  "preset": "WEBP",
  "target": "webp",
  "converted": 2,
  "skipped": 0,
  "failed": 1,
  "files": [
    {
      "source": "D:\\Exports\\cover.png",
      "state": "done",
      "outputs": [ "D:\\Exports\\cover.webp" ]
    },
    {
      "source": "D:\\Exports\\broken.png",
      "state": "failed",
      "outputs": [],
      "error": "The engine reported an error (improper image header)"
    }
  ]
}

종료 코드

0실패한 파일 없음
1일부 파일 실패(나머지는 변환됨)
2잘못된 인자, 모르는 형식이나 프리셋, 없는 입력 파일
3변환할 파일 없음

PowerShell 예시

$result = kiln convert D:\Exports\*.png --to webp --json | Out-String | ConvertFrom-Json
if ($LASTEXITCODE -eq 1) {
  $result.files | Where-Object state -eq 'failed' | ForEach-Object { "$($_.source): $($_.error)" }
}

알아 두면 좋은 점

  • 앱과 같은 엔진과 프리셋을 써요. Kiln에서 만들거나 고친 프리셋을 바로 --preset에 ID나 이름으로 쓸 수 있어요.
  • 추가 엔진(FFmpeg, LibreOffice 등)은 앱의 설정 → 엔진에서 설치해요. kiln formats <형식>으로 엔진이 필요한 변환을 확인할 수 있어요.
  • 와일드카드는 kiln이 직접 풀기 때문에 명령 프롬프트에서도 PowerShell처럼 *.heic를 쓸 수 있어요. 공백이 있는 경로는 따옴표로 감싸세요.
  • 아무것도 업로드하지 않고 인터넷도 필요 없어요. 앱처럼 내 PC에서 변환해요.
  • 메시지는 영어로 나와요. 그래서 어느 PC에서든 스크립트와 로그 내용이 같아요.
